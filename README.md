# Kombucha Bites

Site de uma página, sem build. Todo o conteúdo está em `index.html` (a foto das garrafas já vai dentro do arquivo).

## Publicar no Vercel
1. Suba esta pasta para um repositório no GitHub.
2. No Vercel: Add New > Project > escolha o repositório.
3. Framework Preset: **Other**. Deixe Build Command e Output Directory vazios. Deploy.

## Onde mudar as coisas
- Número do WhatsApp: procure `5562993574534` (link) e `62 99357-4534` (texto) no `index.html`.
- Mensagem que o cliente envia: variável `msg` no script, no fim do arquivo.
- Stories: seção "Stories prontos". Fica visível para quem abrir o site; se quiser só para você, avise que eu separo em uma página escondida.
